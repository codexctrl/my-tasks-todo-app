# My Tasks — To-Do List App

A clean, dark-themed to-do list website built using HTML, CSS, and JavaScript.

## Features

- Add, edit, complete, and delete tasks
- Filter tasks by All, Active, and Completed
- Set task priorities: Low, Medium, and High
- Add and edit task due dates
- Track completed tasks with a live progress bar
- Automatically save tasks using browser localStorage
- Responsive layout for desktop and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No backend or database setup is required.
